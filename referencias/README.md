# Referências

Materiais de referência para a produção do vídeo.

```
referencias/
├── imagens/   # 10 imagens de referência
├── audio/     # áudio da narração
└── copy/      # arquivo de texto com a copy/narração
```

| Pasta      | Conteúdo esperado                                  |
| ---------- | -------------------------------------------------- |
| `imagens/` | Imagens de referência (ex.: `.jpg`, `.png`, `.webp`) |
| `audio/`   | Áudio da narração (ex.: `.mp3`, `.wav`, `.m4a`)      |
| `copy/`    | Texto da copy/narração (ex.: `.txt`, `.md`)          |

Os arquivos `.gitkeep` existem apenas para versionar as pastas vazias e podem ser removidos assim que houver conteúdo dentro delas.
